# Selah Timer

A service timer for churches. Version 0.1.5.

- [Download for Windows](https://raw.githubusercontent.com/devpanther/selah-timer-downloads/main/SelahTimer-windows-setup.exe) (Windows 10 or newer)
- [Download for Mac](https://raw.githubusercontent.com/devpanther/selah-timer-downloads/main/SelahTimer-mac.dmg) (macOS 10.15 or newer)

Selah Timer updates itself from here. This repository holds only the downloads.

## What's new in 0.1.5

- Selah Timer: service timer with plans, projector output, phone remote and release setup
- In-app updates from a public downloads repo, signed releases, self-hosted Mac runner setup
- Waiting on the Up next screen is the default when an item ends
- End service now from any item; 12 or 24 hour clock setting
- Setup: copy the runner program from Selah Live's runner instead of downloading it; show download progress and resume
- Setup: copy bin/runsvc.sh with the runner, and finish the service step when run again
- Projector output only on a second display; says so when none is connected
- Service times: plans without a start time, real-clock start column, warning when a service runs into the next
- Time up designs A, C and G; clock items; bigger item titles
